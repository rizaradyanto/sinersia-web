FOLDER GAMBAR (images/)
=======================

Letakkan semua gambar website di folder ini.

File yang sudah ada:
- logo-sinersia.png      -> logo utama (latar transparan), dipakai di header & footer
- logo-sinersia-alt.png  -> alternatif logo (cadangan)

Tips:
1. Gunakan nama file huruf kecil dan tanpa spasi, contoh: foto-pelatihan.jpg
2. Format yang disarankan: .png untuk logo, .jpg untuk foto.
3. Ukuran gambar sebaiknya di bawah 300 KB agar website cepat dibuka.
4. Panggil gambar dari HTML dengan path relatif, contoh:
   <img src="images/foto-pelatihan.jpg" alt="Pelatihan SINERSIA" />
